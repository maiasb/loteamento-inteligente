⚡ TESTE RÁPIDO (5 MINUTOS)
───────────────────────────────────────────────────────────────────────

  1️⃣  Verificar Status
      $ ./check-deploy-status.sh

  2️⃣  Instalar Dependências
      $ npm install

  3️⃣  Configurar Ambiente
      $ cp .env.example .env.local
      $ nano .env.local  # Editar com credenciais

  4️⃣  Iniciar Servidor
      $ npm run dev

  5️⃣  Testar no Navegador
      → http://localhost:3000

❌ PROBLEMA IDENTIFICADO
───────────────────────────────────────────────────────────────────────

  Causa:      Conflito entre GitHub Pages e API Routes
  
  Detalhes:   - GitHub Pages só suporta sites estáticos
              - Sistema usa 58 API Routes dinâmicas
              - Config atual: output: 'export' desabilitado
              - Workflow espera pasta out/ que não é gerada
  
  Impacto:    - Últimos 5+ deploys falharam
              - Deploy automático não funciona
              - Sistema local não é afetado
